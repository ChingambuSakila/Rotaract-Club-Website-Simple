# 2. Project Plan (WBS) and Schedule

Dates are proposed and should be adjusted to the university calendar.

## 2.1 Work breakdown structure

**1. Project management**
- 1.1 Charter and approvals
- 1.2 Weekly planning and progress reports
- 1.3 Risk and change log maintenance
- 1.4 Closure and handover

**2. Requirements and content**
- 2.1 Stakeholder consultation
- 2.2 Requirements (SRS) approval
- 2.3 Content inventory and collection (text, photos, statistics, logos)
- 2.4 Brand confirmation (cranberry value, logo rules)

**3. Design**
- 3.1 Site map and page wireframes
- 3.2 Design tokens (colours, typography, spacing)
- 3.3 Component design (header, cards, stats, forms, footer)
- 3.4 Design review and approval

**4. Development**
- 4.1 Repository setup and project structure
- 4.2 Shared CSS and JavaScript
- 4.3 Home page
- 4.4 About Us page
- 4.5 Our Impact page
- 4.6 Events page
- 4.7 Contact & Join Us page and form
- 4.8 Content integration

**5. Quality assurance**
- 5.1 Responsive testing (phone, tablet, desktop)
- 5.2 Cross-browser testing
- 5.3 Accessibility and performance checks
- 5.4 Content accuracy review
- 5.5 Defect fixing and retest

**6. Deployment and launch**
- 6.1 Hosting and domain setup
- 6.2 Launch checklist (SEO tags, links, HTTPS)
- 6.3 Go-live and announcement

**7. Handover and learning**
- 7.1 Content-update guide
- 7.2 Developer learning notes (architecture, CSS, Git)
- 7.3 Lessons learned review

## 2.3 Dependencies and critical path

Approved SRS leads to design approval, which leads to build, then testing, then launch. The critical dependencies on the club are: brand confirmation (week 2), content delivery (week 6), and acceptance sign-off (week 10). A one-week delay in any of these moves go-live by the same amount unless the festive buffer absorbs it.

## 2.4 Effort guide for the developer

Plan roughly 8 to 10 hours per week during build weeks and 4 to 6 hours in other weeks. Each build week should end with a committed, working increment and a short learning note covering what concept was applied and why.

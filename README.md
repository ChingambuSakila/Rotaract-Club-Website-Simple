# Rotaract Club of UNZA Website
Static site: HTML5, CSS3, JavaScript. No build step.

## Run locally
Open `index.html` in a browser (or use the VS Code "Live Server" extension).

## Structure
- `*.html` one file per page (shared header/footer copied in each)
- `css/styles.css` design tokens (colours) are at the top in `:root`
- `js/main.js` menu toggle and form validation
- `images/` club photos, logo (add optimised .webp/.jpg)
